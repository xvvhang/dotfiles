# dotfiles

## Idea

This repository manages dotfiles using a bare Git repository:

- A bare Git repository is created (for example, at `$HOME/.dotfiles`).
- The `$HOME` directory is used as the working tree.
- Git commands use `--git-dir` to point to the bare repository and `--work-tree` to point to the home directory.

> **Note:**
> This method can manage dotfiles both in the home directory and in subdirectories such as `$HOME/.config`, following the [XDG Base Directory Specification](https://specifications.freedesktop.org/basedir-spec/basedir-spec-latest.html).

## Usage

1. Make sure the home directory (including subdirectories like `.config`) does not contain conflicting files. Backup or remove files that will be managed by dotfiles.

2. Clone the bare repository:
   `git clone --bare <git-repo-url> $HOME/.dotfiles`

3. Check out the files:
   `git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME checkout`
   If there are errors about existing files, move them and run the command again.

4. Set an alias:
   `alias dotfiles='git --git-dir=$HOME/.dotfiles/ --work-tree=$HOME'`

5. Ignore the bare repo:
   Add `.dotfiles` to `$HOME/.gitignore` and run
   `dotfiles config --local status.showUntrackedFiles no`

6. Use the alias to manage dotfiles:
   - Manage files in the home directory: `dotfiles add .bashrc`
   - Manage files in subdirectories like `.config`: `dotfiles add .config/nvim/init.vim`
   - Commit changes: `dotfiles commit -m "Update config"`
   - Push to remote: `dotfiles push`
